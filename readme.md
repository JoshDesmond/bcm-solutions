# BCMSolutions
This is the website for bcmconsultingllc.com, a consulting service

## Tech
The website is built with
 - Vite
 - React
 - Tailwind
 - EmailJS
 - Shadcn

Deployment and hosted is handled by [Archeplex](https://github.com/JoshDesmond/Archeplex)

## On Automated Deployments
The deployment process is still semi-manual. When code changes are pushed to this repository, I will recieve a notification, and be able to deploy the website from my developer machine. A fix to automate this process with GitHub actions is in progress.
